# Plan 114-01

## Goal

Define the first core operator CLI delivery family so assistant, chat, session, and inspect flows stop depending conceptually on the legacy command tree.

## Steps

1. Map assistant and chat flows to a native CLI delivery module over `AssistantConversationPort`.
2. Map session flows to native delivery over `SessionManagementPort` and inspect flows to native delivery over `InspectionPort`.
3. Verify that parsing and rendering remain edge concerns instead of regaining orchestration ownership.

# Plan 113-01

## Goal

Make the native CLI dispatch path explicit enough that later implementation can replace the `main.rs` routing monopoly without rediscovering ownership boundaries.

## Steps

1. Define native CLI dispatch ownership in `openrustclaw-cli`.
2. Define the dispatch path in terms of app-port invocation instead of command-module cross-calls.
3. Verify that the roadmap preserves the `openrustclaw` binary while narrowing `main.rs` toward bootstrap-only ownership.

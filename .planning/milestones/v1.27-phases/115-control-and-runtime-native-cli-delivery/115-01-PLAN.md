# Plan 115-01

## Goal

Define native CLI ownership for control and runtime entrypoints so those operator flows can leave the legacy command hubs without rediscovering delivery boundaries.

## Steps

1. Map control CLI entrypoints to a native delivery module over `ControlPlanePort`.
2. Map runtime CLI entrypoints to a native delivery module over `RuntimeOperationsPort`.
3. Verify that compatibility shims, if needed, stay bounded and do not regain orchestration ownership.

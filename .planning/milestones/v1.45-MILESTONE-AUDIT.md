# v1.45 Milestone Audit

**Milestone:** `v1.45 Agent Fabric, Routing Console, and Guided Delegation`  
**Status:** shipped  
**Completed:** 2026-04-08

## Goal Check

`v1.45` set out to turn delegated local-agent lanes into a real execution fabric with truthful Cursor support, trusted remote backends, a dedicated routing console, and a smoother first-task experience. That goal is met.

## Shipped Outcomes

- Cursor is now treated as a supported delegated backend when its documented local `cursor agent` surface is present, with auth and model discovery evidence preserved explicitly.
- Trusted remote hosts can be enrolled into a multi-host agent fabric, exported from local inventory, and compared against local delegated capacity.
- Delegated route policy now records durable route receipts, recovery hints, and portable remote execution envelopes instead of leaving multi-host routing implicit.
- Control UI, CLI, and inspect now share one routing-console story for backend inventory, routeability, policy state, and recent route receipts.
- The first task after onboarding or repair now has a prefilled launch plan with a route preview, orchestration request, and fallback choices.

# Plan 69-01: Extract the Voice Plugin Binding Lane

## Objective

Move the voice-plugin bind mutation lane out of inline `skills.rs` orchestration and behind a greenfield application-layer service.

## Steps

1. Add a voice-plugin binding service to `openrustclaw-app`.
2. Replace the inline binding validation and binding record shaping in `skills.rs` with an adapter into that service.
3. Preserve the current voice-plugin bind contract through focused regression tests on the new service and the workspace skill binding path.

## Verification

- `cargo test -p openrustclaw-app skill_voice_plugin_binding -- --nocapture`
- `cargo test -p openrustclaw-cli bind_voice_plugin_data_uses_service_lane -- --nocapture`

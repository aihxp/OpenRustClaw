# Plan 71-01: Extract the Runtime Reload Planning Lane

## Objective

Move the runtime reload-plan seam out of inline `runtime.rs` orchestration and behind a greenfield application-layer service.

## Steps

1. Add a runtime reload-planning service to `openrustclaw-app`.
2. Replace the inline reload-plan comparison logic in `runtime.rs` with an adapter into that service.
3. Preserve the current runtime reload-plan contract through focused regression tests on the new service and the workspace reload-state path.

## Verification

- `cargo test -p openrustclaw-app runtime_reload_planning -- --nocapture`
- `cargo test -p openrustclaw-cli runtime_reload_plan_uses_service_lane -- --nocapture`

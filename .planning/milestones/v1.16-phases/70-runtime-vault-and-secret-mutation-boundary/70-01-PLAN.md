# Plan 70-01: Extract the Runtime Vault Mutation Lane

## Objective

Move the runtime vault set and delete mutation lane out of inline `runtime.rs` orchestration and behind a greenfield application-layer service.

## Steps

1. Add a runtime vault service to `openrustclaw-app`.
2. Replace the inline vault mutation logic in `runtime.rs` with an adapter into that service.
3. Preserve the current runtime vault mutation contract through focused regression tests on the new service and the workspace vault path.

## Verification

- `cargo test -p openrustclaw-app runtime_vault -- --nocapture`
- `cargo test -p openrustclaw-cli set_and_delete_vault_secret_use_service_lane -- --nocapture`

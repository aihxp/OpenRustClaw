# Plan 72-01: Extract the Runtime Vault Control Route Family

## Objective

Move the `/control/runtime/vault` route family out of inline `start.rs` orchestration and behind a greenfield application-layer control service.

## Steps

1. Add a runtime vault control service to `openrustclaw-app`.
2. Replace the inline vault route-family behavior in `start.rs` with an adapter into that service.
3. Preserve the current `/control/runtime/vault` contract through focused regression tests on the new service and the runtime control router.

## Verification

- `cargo test -p openrustclaw-app runtime_vault_control -- --nocapture`
- `cargo test -p openrustclaw-cli runtime_vault_route_family_uses_service_lane -- --nocapture`

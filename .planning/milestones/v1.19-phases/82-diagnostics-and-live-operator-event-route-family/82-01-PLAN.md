# Plan 82-01: Extract the Diagnostics and Live Event Route Family

## Objective

Move diagnostics report collection, websocket event shaping, and interval normalization out of `start.rs` and behind one shared application-layer service.

## Steps

1. Add a control diagnostics service to `openrustclaw-app` for diagnostics report collection, websocket event shaping, and interval normalization.
2. Replace the inline diagnostics orchestration in `start.rs` with adapters into that service.
3. Verify the shipped diagnostics route family still preserves the current contract.

## Verification

- `cargo test -p openrustclaw-app control_diagnostics -- --nocapture`
- `cargo test -p openrustclaw-cli diagnostics_route_family_uses_service_lane -- --nocapture`

# Plan 81-01: Extract the Control Config Route Family

## Objective

Move the control config read, validate, and update orchestration out of `start.rs` and behind one shared application-layer service.

## Steps

1. Add a control config service to `openrustclaw-app` for config loading, rendering, validation, and mutation-result shaping.
2. Replace the inline config validation and update orchestration in `start.rs` with adapters into that service.
3. Verify the shipped `/control/config` route family still preserves the current contract.

## Verification

- `cargo test -p openrustclaw-app control_config -- --nocapture`
- `cargo test -p openrustclaw-cli control_config_route_family_uses_service_lane -- --nocapture`

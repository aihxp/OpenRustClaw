# Plan 109-01

## Goal

Make the native control HTTP route-ownership path explicit enough that later implementation can move routes out of `start.rs` without rediscovering boundaries.

## Steps

1. Define native control-route registration and HTTP shaping ownership in `openrustclaw-gateway`.
2. Define `ControlPlanePort` as the app-facing contract for the control delivery layer.
3. Verify that the roadmap leaves a narrow compatibility-preserving retirement slice for `start.rs`.

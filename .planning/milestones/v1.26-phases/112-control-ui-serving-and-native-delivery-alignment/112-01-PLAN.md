# Plan 112-01

Make the Control UI serving path part of the native gateway-delivery contract instead of leaving the UI coupled to the legacy bootstrap layer.

## Steps

1. Define native ownership for Control UI asset or HTML serving.

3. Verify that the roadmap preserves compatibility while advancing the native-delivery denominator to `2/8`.

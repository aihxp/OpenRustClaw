# Plan 161-01: End-to-End Verification Matrix

## Goal

Run the repo's existing product-level verification surfaces and capture a truthful pass or fail matrix for the shipped system.

## Steps

1. Run the standalone E2E runner for harness sanity.
2. Run `openrustclaw-e2e-tests` across the main E2E suite.
3. Run `openrustclaw-integration-tests` across the integration suite.
4. Record which areas passed, failed, or were environment-blocked.

## Verification

- The phase uses the existing E2E and integration crates rather than ad hoc confidence checks.
- The resulting matrix is concrete enough to drive ownership triage in Phase 162.

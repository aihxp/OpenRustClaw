# Plan 68-01: Extract the Runtime Provider Switch Lane

## Objective

Move the runtime switch-provider and switch-model mutation lane out of inline `runtime.rs` orchestration and behind a greenfield application-layer service.

## Steps

1. Add a runtime provider-switch service to `openrustclaw-app`.
2. Replace the inline switch-provider and switch-model orchestration in `runtime.rs` with an adapter into that service.
3. Preserve the current runtime mutation contract through focused regression tests on the new service and the persisted runtime config path.

## Verification

- `cargo test -p openrustclaw-app runtime_provider_switch -- --nocapture`
- `cargo test -p openrustclaw-cli switch_provider_updates_runtime_config_through_service_lane -- --nocapture`

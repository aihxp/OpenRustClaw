# Plan 154-01

## Goal

Define the delete-or-shim rules for still-live legacy surfaces so compatibility no longer preserves hidden command-tree ownership.

## Steps

1. Identify when a legacy surface survives temporarily as a shim and when it should be hard-deleted.
2. Replace implicit compatibility assumptions with bounded delete-or-shim rules in the roadmap.
3. Verify that the retirement slice stays concrete enough to implement without rediscovering compatibility rules.

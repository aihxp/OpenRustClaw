# Plan 122-01

## Goal

Define the startup-boundary contracts needed for native runtime-host delivery so service-manager, probes, maintenance, and scheduler flows have explicit ownership.

## Steps

1. Map each startup concern to a native owner and the app or adapter contracts it depends on.
2. Replace command-local helper assumptions with delivery or infrastructure boundary language in the roadmap.
3. Verify that the runtime-host story is concrete enough to implement without rediscovering startup ownership.

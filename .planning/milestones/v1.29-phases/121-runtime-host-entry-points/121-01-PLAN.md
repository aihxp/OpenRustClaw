# Plan 121-01

## Goal

Define the dedicated runtime-host and background-worker entrypoints so worker startup no longer defaults conceptually to the legacy command layer.

## Steps

1. Map runtime-host bootstrap and background-worker bootstrap to explicit native delivery owners.
2. Tie those entrypoints to app ports instead of legacy startup helpers.
3. Verify that the roadmap leaves an incremental implementation path for replacing legacy worker startup.

# Plan 124-01

## Goal

Define the bounded compatibility and removal rules for legacy command ownership over worker lifecycle startup so the next implementation slice can reduce that ownership truthfully.

## Steps

1. Identify which legacy startup surfaces may remain temporarily and in what reduced state.
2. Define what those surfaces are no longer allowed to own once native runtime-host entrypoints exist.
3. Verify that the roadmap only advances to `5/8` because the removal rules are explicit end to end.

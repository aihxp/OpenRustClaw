# Plan 123-01

## Goal

Align the major worker families to the native runtime-host delivery path so mobile, voice, and orchestration startup stop being separate legacy ownership exceptions.

## Steps

1. Map mobile, voice, and orchestration worker startup to app ports and native runtime-host delivery targets.
2. Define the compatibility rules for any still-live worker-family command entrypoints.
3. Verify that the roadmap keeps the worker story shared and incremental instead of fragmented by legacy file ownership.

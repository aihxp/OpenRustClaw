# Plan 157-01: Native Delivery Scorecard Verification

## Goal

Produce an evidence-backed scorecard for the native-delivery claim using direct source-tree inspection.

## Steps

1. Run `cargo metadata` to confirm the live crate topology.
2. Measure the native and legacy entrypoint hotspots with `wc -l`.
3. Inspect the current wiring in `main.rs`, `commands/mod.rs`, `gateway`, and `mcp`.
4. Record the resulting scorecard and claim boundary in the milestone artifacts.

## Verification

- The scorecard cites direct codebase evidence.
- The scorecard distinguishes implemented native ownership from surviving legacy delivery surfaces.

# Plan 25-01: Branch Onboarding By Deployment Path

## Goal

Make the onboarding wizard ask for a deployment path up front and persist that choice into the self-hosted product-mode contract.

## Must Have

- onboarding offers solo, team, company, and enterprise paths
- the selected path is saved through the self-hosted manifest
- onboarding defaults reflect the chosen path instead of treating every install the same

## Expected Files

- `crates/cli/src/commands/onboard.rs`
- `crates/cli/src/commands/self_hosted.rs`

## Verification

- targeted onboarding tests for default state, mode-aware defaults, and workspace-status behavior

# Plan 77-01: Extract the Remaining Skills Lifecycle Seam

## Objective

Move the background workflow scheduling and channel-extension binding decision logic out of `skills.rs` and behind one shared application-layer lifecycle service.

## Steps

1. Add a skills lifecycle service to `openrustclaw-app` for background scheduling and channel-extension binding.
2. Replace the inline trigger, metadata, and result-shaping logic in `skills.rs` with adapters into that service.
3. Verify the CLI scheduling and channel-extension binding flows still preserve the shipped contract.

## Verification

- `cargo test -p openrustclaw-app skill_channel_extension_lifecycle -- --nocapture`
- `cargo test -p openrustclaw-cli schedule_and_bind_channel_extension_use_service_lane -- --nocapture`

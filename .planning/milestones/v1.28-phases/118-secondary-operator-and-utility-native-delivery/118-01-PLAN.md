# Plan 118-01

## Goal

Define the native delivery ownership for the remaining secondary operator and utility families so the second CLI slice covers the full operator surface instead of only the largest hotspots.

## Steps

1. Map channels, services, schedule, tools, media, and memory flows to native CLI modules over their relevant app ports.
2. Group those families by delivery concern rather than by legacy file layout.
3. Verify that the roadmap is explicit enough to implement the second CLI slice without rediscovering ownership.

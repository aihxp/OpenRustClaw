<decisions>
## Implementation Decisions

- Treat the secondary operator and utility families as first-class product surface, not as leftover cleanup behind the larger command hubs.
- Group them by app-port and delivery concern rather than by inherited legacy file layout.
- Keep the native CLI scope explicit enough that later milestones can implement these modules without rediscovering family boundaries.

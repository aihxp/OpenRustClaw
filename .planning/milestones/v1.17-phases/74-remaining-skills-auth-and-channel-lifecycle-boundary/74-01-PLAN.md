# Plan 74-01: Extract the Auth-Plugin Bind Lifecycle Lane

## Objective

Move auth-plugin bind validation, default-key derivation, and binding composition out of `skills.rs` and behind a greenfield application service.

## Steps

1. Add an auth-plugin binding service to `openrustclaw-app`.
2. Replace the inline bind logic in `skills.rs` with an adapter into that service.
3. Verify the persisted registry and CLI response still reflect the shipped contract.

## Verification

- `cargo test -p openrustclaw-app skill_auth_plugin_binding -- --nocapture`
- `cargo test -p openrustclaw-cli bind_auth_plugin_data_uses_service_lane -- --nocapture`

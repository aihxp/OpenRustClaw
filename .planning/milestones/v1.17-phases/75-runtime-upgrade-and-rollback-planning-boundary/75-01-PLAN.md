# Plan 75-01: Extract the Runtime Maintenance Planning Seam

## Objective

Move runtime upgrade, self-update, and rollback planning logic out of `runtime.rs` and behind one shared application-layer maintenance-planning service.

## Steps

1. Add a runtime maintenance-planning service to `openrustclaw-app`.
2. Replace inline blocker and step generation in `runtime.rs` with adapters into that service.
3. Verify the CLI and route-facing plan outputs still preserve the shipped maintenance guidance.

## Verification

- `cargo test -p openrustclaw-app runtime_maintenance_planning -- --nocapture`
- `cargo test -p openrustclaw-cli runtime_maintenance_plans_use_service_lane -- --nocapture`

# Plan 150-01

## Goal

Define the first integration gateway slice so provider, channel, and external service integrations have explicit successor ownership under native infrastructure contracts.

## Steps

1. Map each integration concern to a native gateway owner and the contracts it depends on.
2. Replace legacy command-local side-effect assumptions with explicit integration-boundary language in the roadmap.
3. Verify that the integration gateway story is concrete enough to implement without rediscovering side-effect ownership.

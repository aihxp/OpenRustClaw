# Plan 29-03: Validate Channel Bootstrap During Onboarding

## Why

Channel setup currently saves tokens but does not use the shipped probe surface before telling the operator setup succeeded. That breaks the trust contract established in earlier milestones.

## Implementation

1. After a shipped channel is configured, refresh the channel probe report and inspect the selected platform outcome.
2. Persist the channel bootstrap outcome in setup state so later repair and handoff work can reuse it.
3. Treat unsupported or failed bootstrap paths honestly instead of claiming they were configured successfully.

- `cargo test -p openrustclaw-cli onboard -- --nocapture`

# Plan 127-01

## Goal

Define how app ports connect to repositories and gateway adapters directly so app services stop depending conceptually on command-local filesystem and registry helpers.

## Steps

1. Map the major app-port families to repository and gateway contracts explicitly.
2. Replace command-local persistence-helper ownership with adapter-backed app-service ownership in the roadmap.
3. Verify that the milestone preserves a bounded migration story for any still-live compatibility shims while app services move to adapter-backed ownership.

# Plan 22-01: Add A Durable Full-Autonomy Override Contract

## Goal

Introduce a file-backed enterprise full-autonomy contract with explicit enablement state, operator attribution, and bounded runtime budgets.

## Must Have

- full autonomy is stored as a separate enterprise override instead of being inferred from raw runtime autonomy fields
- the manifest records who enabled it, when it changed, and which budgets or approval overrides are active
- typed inspection can summarize the current full-autonomy state for operator-facing surfaces

## Expected Files

- `crates/cli/src/commands/enterprise_autonomy.rs`
- `crates/cli/src/commands/inspect.rs`
- `crates/cli/src/commands/mod.rs`

## Verification

- targeted unit tests for manifest defaults, enable or disable transitions, and typed summary coverage

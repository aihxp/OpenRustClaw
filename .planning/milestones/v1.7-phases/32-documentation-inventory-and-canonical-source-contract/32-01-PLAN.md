# Plan 32-01: Audit README, Repo-Root Docs, and mdBook Overlap

## Why

The repo currently has a valid but fuzzy docs model. Before rewriting, the milestone needs one inventory of which surfaces overlap and which of them should remain authoritative.

## Implementation

1. Review `README.md`, repo-root docs under `docs/`, and mdBook entry points under `docs/src/`.
2. Identify canonical, mirrored, and stale or cleanup-target surfaces.
3. Capture the inventory as a durable docs contract rather than leaving it as ephemeral milestone context.

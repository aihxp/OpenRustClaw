# Plan 107-01

## Goal

Define the successor native delivery crates or modules and the bootstrap contract for the main product entrypoints.

## Steps

1. Choose the target delivery layers for CLI, gateway or control HTTP, MCP, runtime-host, and infrastructure adaptation.
2. Define how the main binary, control server, MCP server, and worker hosts should bootstrap through those layers.
3. Verify that the topology preserves shipped behavior during migration instead of assuming a big-bang rewrite.

# Phase 6 Plan 01: Add a unified operator-ops runtime summary

## Objective
- **What:** Compose the existing runtime operations primitives into one control-surface summary for deploy, restart, and recovery decisions.
- **Why:** Phase 6 cannot claim production-ready operator ops if health, service-install, lock, and recovery information remain fragmented across separate commands and endpoints.
- **Output:** A typed runtime operator summary and corresponding Control UI panel for deploy-run-recover visibility.

# Phase 4 Plan 01: Add a durable execution ledger for tool and MCP runs

## Objective
- **What:** Persist a durable, inspectable execution ledger for runtime tool and MCP calls.
- **Why:** Phase 4 cannot claim bounded or auditable tool behavior while operators still have to reconstruct failures from logs and trace side channels.
- **Output:** A workspace-local execution record model plus control inspection surfaces showing recent tool or MCP outcomes.

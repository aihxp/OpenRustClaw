- Phase 61 expanded the application lane from one proving slice to a second typed operator summary family, proving the setup-handoff pattern was reusable.
- Phase 62 converted that summary-first migration into a real control-route seam so `start.rs` stopped owning the self-hosted product-mode orchestration directly.
- Phase 63 showed the same greenfield pattern works on another operator-facing surface with distinct data loading and attention-signal rules.
- Phase 64 extended the approach into the `skills.rs` hotspot and the MCP/runtime surface, creating the first shared compiled-skill overview seam instead of leaving skills behavior split across multiple legacy adapters.

- Typed operator summaries now have multiple real homes in `openrustclaw-app` instead of defaulting back to `inspect.rs`.

- The mobile operator surface remains stable while report composition and attention-signal derivation now live outside the CLI hotspot.
- The compiled-skill CLI preview flow and the compiled-skill MCP/runtime tool surface both continue to work while sharing the same application-level overview service.

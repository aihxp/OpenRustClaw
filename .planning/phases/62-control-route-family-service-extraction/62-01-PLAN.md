# Plan 62-01: Extract a Bounded Control Route Family Behind an Application Service Seam

## Objective

Move the `/control/self-hosted/product-mode` transition path out of `start.rs` business-logic ownership and behind an `openrustclaw-app` service seam.

## Steps

1. Extend the self-hosted product-mode application lane with a transition-and-report service contract.
2. Replace the inline route orchestration in `start.rs` with a bounded adapter call through `inspect.rs` into that new service.
3. Preserve the shipped runtime and Control UI contract through focused regression tests for the migrated transition path.

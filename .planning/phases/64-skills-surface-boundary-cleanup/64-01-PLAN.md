# Plan 64-01: Extract the First Stable Service Seam from `skills.rs`

## Objective

Move the read-only compiled-skill overview lane out of `crates/cli/src/commands/skills.rs` and behind a shared application-layer service.

## Steps

1. Add a compiled-skill overview service to `openrustclaw-app`.
2. Replace the duplicated compiled-skill read helpers in `skills.rs` and `start.rs` with calls into that service.
3. Preserve the current compiled-skill CLI and MCP behavior through focused regression tests.

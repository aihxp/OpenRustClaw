# Plan 25-02: Reflect Deployment Path In First-Start Diagnostics

## Goal

Carry the selected deployment mode into workspace status and doctor output so first-start trust reflects the operator’s chosen path.

- workspace-status output shows whether a self-hosted deployment path is already selected
- doctor surfaces missing explicit product mode as a warning
- first-start readiness behavior stays truthful and does not become stricter than intended

## Expected Files

- `crates/cli/src/commands/onboard.rs`
- `crates/cli/src/commands/doctor.rs`

## Verification

- targeted doctor tests for warning-only behavior and onboarding tests for status reporting

# Plan 28-02: Resume Onboarding with Standard, Advanced, and Custom Paths

## Goal

Make onboarding resumable from durable setup state and expose a clear standard path plus advanced or custom setup paths.

## Must Have

- onboarding offers resume when setup-state indicates unfinished work
- setup path is explicit as standard, advanced, or custom
- custom setup can choose the step set without creating a disconnected onboarding flow

## Expected Files

- `crates/cli/src/commands/onboard.rs`

## Verification

- targeted onboarding tests for resume behavior and setup-path selection defaults

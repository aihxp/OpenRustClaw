# Plan 177-01: Provider access-mode selection and resume state

## Objective
- **What:** Rework the onboarding model step so provider choice and access-mode context are explicit, truthful, and resume-aware.
- **Why:** The current onboarding flow hardcodes provider prompts and loses too much context when re-entering the model step, which blocks the later verification and model-selection phases from building on a trustworthy provider-path foundation.
- **Output:** A provider-path selection flow in onboarding plus durable setup-state fields that preserve provider and access-mode context through resume.

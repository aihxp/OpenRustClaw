# Plan 49-01: Lock the First Public Crate Boundary

## Objective

Make the first crates.io surface explicit and remove the current package metadata gaps for the selected crate.

## Steps

1. Audit the workspace manifests and dependency shape to choose the initial publishable crate set.
2. Normalize workspace and `openrustclaw-core` package metadata for crates.io discovery.
3. Re-run package inspection and dry-run packaging to verify the selected target is clean and the non-target workspace remains out of the first publish scope.

## Verification

- `cargo metadata --no-deps --format-version 1 | jq -r '.packages[] | select(.name=="openrustclaw-core") | {name,version,description,license,repository,readme,documentation,homepage,keywords,categories}'`
- `cargo package -p openrustclaw-core --allow-dirty --no-verify`

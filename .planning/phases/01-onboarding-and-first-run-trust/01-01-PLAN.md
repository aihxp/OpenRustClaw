# Phase 1 Plan 01: Harden first-start onboarding readiness

## Objective
- **What:** Tighten the onboarding health gate so first-run validation blocks obvious broken launches and explains why.
- **Why:** Phase 1 needs first-start trust, and the current warning-only path can still offer the assistant when required provider setup is missing.
- **Output:** A first-start readiness policy in doctor/onboard, targeted tests, and aligned quickstart guidance.

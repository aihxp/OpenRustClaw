# Plan 67-01: Extract the Skill Registry Mutation Lane

## Objective

Move the install, update, and uninstall mutation lane out of inline `skills.rs` orchestration and behind a greenfield application-layer service.

## Steps

1. Add a skill registry mutation service to `openrustclaw-app`.
2. Replace the inline install, update, and uninstall orchestration in `skills.rs` with an adapter into that service.
3. Preserve the current mutation contract through focused regression tests on the new service and the workspace-skill install or uninstall path.

## Verification

- `cargo test -p openrustclaw-app skill_registry_mutation -- --nocapture`
- `cargo test -p openrustclaw-cli workspace_skill_install_and_uninstall_data_flow -- --nocapture`

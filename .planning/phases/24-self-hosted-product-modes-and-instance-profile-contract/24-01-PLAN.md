# Plan 24-01: Add A Durable Self-Hosted Product-Mode Contract

## Goal

Introduce a file-backed self-hosted product-mode manifest that makes solo, team, company, and enterprise deployments explicit.

## Must Have

- product mode is stored under the existing control root instead of being implied by docs alone
- the contract distinguishes product mode from runtime execution mode
- the manifest captures enough mode metadata for onboarding and lifecycle transitions to build on later

## Expected Files

- `crates/cli/src/commands/self_hosted.rs`
- `crates/cli/src/commands/mod.rs`

## Verification

- targeted unit tests for default summary behavior, manifest persistence, and mode validation

# Plan 32-02: Define Canonical Ownership and Cleanup Rules

## Why

The rewrite will create more drift unless the repo documents who owns each major docs surface and when a duplicate should be deleted instead of maintained.

## Implementation

2. Add a mdBook entry point so the contract is visible from the docs navigation.
3. Wire the contract into the docs index so later phases can follow it.

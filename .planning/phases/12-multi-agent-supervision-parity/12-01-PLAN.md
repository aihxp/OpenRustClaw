# Phase 12 Plan 01: Add richer typed supervision summaries to orchestration runtime

## Objective
- **What:** Expose richer typed supervision summaries for both completed receipts and active orchestration runs.
- **Why:** Phase 12 cannot claim supervision parity while delegated-run lifecycle state still requires operators to decode low-level JSON or jump across multiple endpoints manually.
- **Output:** Typed receipt and active-run supervision summary helpers in the orchestration command layer.

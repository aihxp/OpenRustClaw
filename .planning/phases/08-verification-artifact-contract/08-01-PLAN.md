# Phase 8 Plan 01: Harden the core verification lifecycle contract

## Objective
- **What:** Add a shared verification readiness inspector and use it to harden bootstrap and phase-complete behavior.
- **Why:** The milestone cannot truthfully automate verification integrity while init and completion commands disagree about whether verification evidence exists.
- **Output:** Shared verification contract logic reused by `init milestone-op` and `phase complete`.

# Plan 31-01: Print an Explicit CLI Setup Handoff

## Why

The onboarding wizard currently ends with a generic configuration recap. It should instead tell the operator whether setup is ready, blocked, or degraded and what to do next.

## Implementation

1. Derive handoff status and detail from durable setup state plus retained bootstrap outcomes.
2. Print that handoff in the onboarding completion output.
3. Add focused unit coverage for the shared handoff helpers if needed.

## Verification

- `cargo test -p openrustclaw-cli onboard -- --nocapture`

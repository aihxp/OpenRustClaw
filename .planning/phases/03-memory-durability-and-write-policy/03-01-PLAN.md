# Phase 3 Plan 01: Enforce explicit assistant memory-write policy

## Objective
- **What:** Add an explicit write gate for the built-in assistant memory tool.
- **Why:** Phase 3 needs a trustworthy memory boundary, and the current `memory_store` tool will persist freeform "important information" with no explicit policy basis.
- **Output:** Stricter memory tool schema and enforcement, aligned prompt guidance, and tests for allowed and blocked writes.

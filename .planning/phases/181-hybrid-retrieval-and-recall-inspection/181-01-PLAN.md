<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query text -> SQLite FTS/vector scoring | Untrusted search text crosses into retrieval ranking and must stay parameterized and bounded |
| stored memory -> recall pack output | Persisted content becomes model-visible or operator-visible summaries and must stay clipped and metadata-driven |
| embedding configuration -> live hybrid retrieval | Missing or misconfigured embeddings can silently degrade ranking unless surfaced explicitly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-181-01-01 | T/I | `crates/db/src/memory_store.rs` | mitigate | Keep parameterized queries, bounded fetch limits, and typed factor output instead of raw SQL or blob exposure |
| T-181-01-02 | I | `crates/memory/src/context.rs`, `crates/agent/src/memory_tools.rs` | mitigate | Preserve the recall-only contract and emit only bounded summaries, never raw memory files or archive blobs |
| T-181-01-03 | R/D | `crates/agent/src/memory_tools.rs`, `crates/gateway/src/server.rs` | mitigate | Surface explicit degraded-state metadata when embeddings are unavailable and cover the hybrid path with automated tests so it cannot silently no-op |
</threat_model>

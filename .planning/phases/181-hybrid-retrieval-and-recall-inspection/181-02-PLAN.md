<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| retrieval explanation payload -> operator output | Ranked-memory details cross into CLI/control/MCP views and must stay bounded and reviewable |
| runtime events -> cross-session inspection | Durable telemetry is queried later and must retain enough detail without exposing raw memory blobs |
| file-backed recall views -> operator edits | Human-edited recall exports re-enter the system and must stay within bounded phase-181 metadata |

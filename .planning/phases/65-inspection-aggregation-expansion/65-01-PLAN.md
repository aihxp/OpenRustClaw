# Plan 65-01: Extract the Enterprise Admin Aggregation Family

## Objective

Move the enterprise admin aggregation out of `crates/cli/src/commands/inspect.rs` and behind a greenfield application-layer service.

## Steps

1. Add an enterprise admin aggregation service to `openrustclaw-app`.
2. Replace the inline enterprise admin composition in `inspect.rs` with an adapter into that service.
3. Preserve the current enterprise admin inspection contract through focused regression tests.

## Verification

- `cargo test -p openrustclaw-app enterprise_admin -- --nocapture`
- `cargo test -p openrustclaw-cli enterprise_admin_summary_combines_access_policy_and_supervision -- --nocapture`

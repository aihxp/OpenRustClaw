# Plan 19-02: Make Enterprise Writes Usable From Control UI

## Goal

Turn the existing enterprise access and policy APIs into a real operator workflow inside `/control/ui`.

## Must Have

- scoped enterprise operator headers can be stored and reused from the browser
- operators can bootstrap enterprise access, upsert operators, update enterprise policy, and export audit evidence from the shipped UI
- UI actions refresh the admin and enterprise surfaces after mutations

## Expected Files

- `crates/cli/src/commands/control_ui.html`
- `crates/cli/src/commands/control_ui.rs`

## Verification

- Control UI tests confirm the new admin panel and action functions exist

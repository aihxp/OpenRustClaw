# Plan 22-02: Enforce Full-Autonomy Enablement, Disable, And Kill-Switch Actions

## Goal

Wire the full-autonomy contract into shipped runtime routes so trusted operators can enable, disable, and kill-switch the stronger autonomy lane with durable evidence.

## Must Have

- runtime routes expose explicit inspect, enable, disable, and kill-switch operations
- enabling full autonomy applies the intended runtime autonomy overrides without changing the default trust-first path for everyone else
- disable and kill-switch actions persist durable operator-visible evidence instead of silently mutating runtime state

## Expected Files

- `crates/cli/src/commands/enterprise_autonomy.rs`
- `crates/cli/src/commands/start.rs`
- `crates/cli/src/commands/enterprise_access.rs`

## Verification

- targeted handler or middleware tests for protected routes, runtime updates, and kill-switch evidence

# Feature Matrix

The source-of-truth shipped-surface matrix lives in `docs/feature-matrix.md` at the repository root.

Use that file to answer:

- what is `real`,
- what is still `partial`,
- what is intentionally `gated`,
- what is `deferred`.

## Current headline

- Gateway, scheduler, core memory, recall memory, MCP stdio, and several tier-1 channel paths are real.
- Discord, RAG quality, observability coverage, and some operator workflows are still partial.
- Voice, mobile, distributed, and several extra channels remain gated from the shipped surface.

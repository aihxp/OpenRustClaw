# Surface Matrix

The source-of-truth surface inventory lives in `docs/surface-matrix.md` at the repository root.

It maps the declared shipped OpenRustClaw surface to:

- current OpenRustClaw status,
- scope class,
- owning modules,
- representative tests,
- local docs,
- delivery risk.

## Why this matters

This is the file that turns the shipped surface from a vague goal into a concrete engineering contract.

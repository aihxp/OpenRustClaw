# Parity Matrix

The source-of-truth parity inventory lives in `docs/parity-matrix.md` at the repository root.

It maps documented OpenClaw feature families to:

- current OpenRustClaw status,
- scope class,
- owning modules,
- representative tests,
- local docs,
- parity gap severity.

## Why this matters

This is the file that turns "feature parity" from a vague goal into a concrete engineering contract.
